Point of Sale Discount Amount

Give the whole order a fixed-amount discount straight from the POS screen — one tap, taxes stay correct, and the total can never go negative.

💡 This is an AMOUNT discount, not a percentage
Odoo's Point of Sale already has a built-in Global Discount feature, and it is percentage-based (e.g. 10% off). This module adds a separate, complementary Discount Amount button for cashiers who instead need to subtract a flat number (e.g. 10.00 off, in your store's currency) — useful for loyalty vouchers, rounding adjustments, or manager-approved fixed-value discounts that a percentage can't express cleanly. Both features can be enabled side by side; they do not replace or conflict with each other.

How it works

Three steps — the cashier never leaves the POS screen.

1
Tap “Discount Amount”
A single button on the POS order screen opens a numeric popup pre-filled with the configured default amount.
2
Taxes are kept correct
The amount is split across every distinct tax group on the order in proportion to its share of the total, so each tax total still reconciles.
3
Adjust as many times as needed
Tapping the button again replaces the previous discount line, so the cashier can freely correct the amount before payment.

Key features

🏷️ Fixed-amount, not percentage
Odoo's built-in Global Discounts are percentage-based. This adds a one-click alternative for a flat amount off — e.g. “take 5 off the total”.
⚖️ Proportional tax-group split
Orders mixing several tax rates are handled correctly — the discount is distributed across tax groups instead of being applied once per group.
🛡️ Never goes negative
The discount is automatically capped at the order's discountable subtotal, so a mistyped amount can't push the total below zero.
🔑 One button, editable anytime
Re-applying the discount replaces the previous line automatically, so the cashier can correct it right up until payment.
⚙️ Per-POS configuration
Enable it per point of sale, choose the discount product and set a default amount from Settings.
⚡ Lightweight, no dependencies
Depends only on Point of Sale — no external services, no extra apps required.

⚙️ Configuration

  1. Install the module (depends on Point of Sale).
  2. Go to Point of Sale > Configuration > Settings and enable Global Discounts on the point of sale you want it active on.
  3. Set the Discount Product (must be sellable and available in Point of Sale) and the default Discount Amount.
  4. Open a POS session — the Discount Amount button now appears on the order screen.
